# AI-Based Terminal Conversational Chatbot

## Project Overview

The AI-Based Terminal Conversational Chatbot is a Python-based application that allows users to communicate with an AI model directly through the VS Code terminal. The chatbot accepts natural language questions, processes the input using an AI language model, and generates meaningful responses.

## Features

- Terminal-based interaction
- AI-powered responses
- Natural language conversation
- Continuous chat within a single session
- Simple and user-friendly interface
- Exit option using `exit`, `quit`, or `bye`

## Technologies Used

- Python
- AI Language Model
- VS Code
- Terminal

## How to Run

1. Clone the repository.
2. Install the required dependencies.
3. Open the project folder in VS Code.
4. Run the chatbot using:

```bash
python terminal_chatbot.py
